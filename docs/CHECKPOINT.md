- Нет подтверждённого серверного доступа к Supabase, настроенных Google OAuth-приложений, Telegram-бота с разрешёнными каналами, токена Freelancehunt и работающего расписания импорта.

- На Windows последняя показанная ошибка: `npm.cmd ci` → `EPERM unlink` для `next-swc.win32-x64-msvc.node`. Вероятная причина — заблокированный процессом файл. Пользователю предложено остановить свой сервер через Ctrl+C, закрыть редактор, повторить `npm.cmd ci` и `npm.cmd run dev -- --port 3000`; при сохранении блокировки — перезагрузка. **Успешное исправление и запуск на его компьютере не подтверждены.**
- Облачный сервер на 3000 не означает доступность localhost на компьютере пользователя; процессы могут не пережить восстановление среды. Не обещать браузерный cloud preview без реально поддерживаемого хостинга.
